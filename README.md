## ES添削ツール
生成AIを使って、就活のエントリーシートを添削するWebアプリです。
公開URL: https://es-checker-jf87khgtnj4nfg8ng38tth.streamlit.app/

## 作った背景
就活でESを書く際、自分では良し悪しを判断しづらく、第三者に見てもらうにも時間がかかるという課題がありました。
生成AIに面接官の視点で評価させることで、何度でも即座にフィードバックを得られる仕組みを作りました。

## 機能

- 設問・回答・志望業界を入力すると、5つの観点で採点
- 各観点について、評価の根拠と改善案を提示
- 改善後の文章例を自動生成

### 設定の外部化
モデル名やAPIキーをコードに直書きせず環境変数から読む構成にしました。
実際、開発中にモデルが世代交代した際、コードを変更せず
設定ファイルの1行修正のみで対応できました。

## 詰まった点と解決方法

### APIキーが認証エラーになる
エラーメッセージからは原因が特定できなかったため、
`repr()` で変数の中身を出力したところ、
サンプルの文字列が本物のキーの前に混入していることが判明しました。
以降、原因不明のエラーではまず変数の中身を確認する手順を取るようにしました。

### 指定したモデルが利用できない
404が返るためモデル一覧を取得して確認したところ、
参照していた情報が古く、該当モデルが新規提供を終了していました。
公式ドキュメントで現行モデルを確認して切り替えました。

### ローカルでは動くがデプロイ先で動かない
ローカルは.envから、クラウドはSecretsから設定を読む必要があり、
両方に対応する読み込み処理を実装しました。
